# Data provenance and reuse

Checked for this implementation: **11 October 2026**. No external map tiles, coordinates, business listings, reviews or opening hours have been ingested.

| Data                                                                                       | Source                                                             | Verification                                                             | Reuse/attribution                                                                                                                          |
| ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------ | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 1st Cross Street, 2nd Cross Street, Sea Street, Maliban Street, Prince Street, Main Street | Street names supplied in the user's project brief                  | Names retained as requested; independent geographic verification pending | No third-party geographic dataset copied                                                                                                   |
| Street/category associations for each of those six streets                                 | Preliminary development associations authored for this application | Unverified; explicitly labelled in public UI                             | Project-maintained seed data; no claim of exclusivity or stock                                                                             |

| Categories, products and English aliases                                                   | Original development vocabulary in `prisma/seed-data.ts`           | Used for discovery/search testing; not inventory claims                  | Original project content                                                                                                                   |
| Coordinates, phone numbers and individual business records                                 | None                                                               | All street coordinates null; shop table not seeded                       | No imported data                                                                                                                           |
| Directions links                                                                           | Google Maps name-based URL construction                            | Google independently resolves the destination; users must confirm it     | See [Google's Maps URL documentation](https://developers.google.com/maps/documentation/urls/get-started); no Google geographic data copied |

Before adding precise locations or public shops, record the original URL/source, individual fact, retrieval date, licensing/reuse permission, verification method/date and required attribution. Do not treat Google directions results as a licensed data import. Do not scrape or copy proprietary business data without permission. Confirm uncertain category associations independently and update this record.

If OpenStreetMap coordinates or tiles are adopted later, record source objects and retrieval date, comply with ODbL and tile-provider terms and display the required OpenStreetMap attribution wherever map data is shown. No OSM map is displayed in this implementation, so there is no current map attribution claim.

Synthetic shop fixtures are clearly prefixed TEST FIXTURE and only created in the guarded local test database. Integration transactions roll back. Browser tests delete their known fixture IDs in `finally`; no test fixtures belong in production or development seeds.

Typography uses DM Sans and Plus Jakarta Sans, distributed through the version-locked Fontsource packages under SIL Open Font License 1.1. The bundled copyright and license notices are retained in `public/licenses/`; font files are self-hosted. No external photography or decorative hero image is used.
